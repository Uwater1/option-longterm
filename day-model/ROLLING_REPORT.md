## Methodology

1. **Rolling Window**: Each model trains on 6 years of data before the lockbox date.
2. **OOS Evaluation**: Each model is tested on its 3-month deployment window (lockbox to lockbox+3m).
3. **Signal Generation**: Within-window percentile rank of model predictions; signal fires when rank >= threshold.
4. **Strategy Returns**: On signal days, P&L = actual `trade_return` (long) or `-trade_return` (short), minus transaction cost.
5. **Warning System**: Based on pre-lockbox outer validation IC only (no OOS peeking).
6. **Artifacts**: Models in `models/rolling/`, results in `data/rolling/`, plots in `plots/rolling/`.
