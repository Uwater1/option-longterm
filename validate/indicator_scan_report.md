# Indicator Scanner Report

## Methodology

- Forward returns computed using vectorized calendar-day search (`np.searchsorted`).
- 14d and 30d forward returns calculated from `close_adj` (or `close`).
- ~30 indicators computed using `pandas-ta` and native pandas.
- Quantile-based thresholds use **expanding-window** (252-day minimum lookback) to eliminate look-ahead bias.
- Single-indicator conditions use both fixed and expanding-quantile thresholds.
- NaN indicator rows (early rolling-window warmup) are explicitly excluded from both triggered and non-triggered groups.
- Combinations: AND/OR of top 10 conditions per metric per ETF (greedy) plus pre-specified known strategy combos.
- Minimum trigger days: 30 (singles), 20 (combinations).
- p-values from Welch's t-test vs non-triggered days.
- Lift = triggered P10 rate / baseline P10 rate.
